# 原始知识 - 小米实习

## 基础信息
- 公司：小米
- 时间：2025.10 - 2026.02
- 岗位：商业化实习生
- 部门：可穿戴设备-软件
- 标签：商业化、会员体系、竞品分析、增长活动
- 概述：会员体系竞品调研与商业化增长活动策划

## 项目1：抖音支付合作项目（4星）
- 类型：商业化
- 问题：小米运动健康App在会员订阅、权益购买等商业化场景中，支付环节是影响最终转化的关键节点。
- 方案：
  1. 在支付落地页新增抖音支付入口，补充主流支付方式供给
  2. 承接抖音支付立减活动，放大优惠对支付决策的促进作用
  3. 设计入口位置、跳转逻辑及异常场景兜底策略
  4. 优化支付页对抖音支付立减活动的宣传方案，缩短用户理解成本
- 成果：支付转化+3% | 优惠点击率+10%+ | 支付能力+1渠道
- 洞察：学会了把支付方式、活动信息和用户决策路径放在一起设计，而不是孤立看某个功能入口。

## 项目2：亲友赠礼老带新活动（3星）
- 类型：增长活动
- 问题：小米运动健康App的会员及健康权益类产品增长，既依赖站内自然转化，也需要借助社交传播提高触达效率。
- 方案：
  1. 设计"发起赠礼→分享触达→好友领取→权益到账"4个核心转化节点
  2. 优化发起赠礼入口、分享触达方式、领取承接页、状态流转与提示文案
  3. 梳理页面规则信息，降低用户理解门槛
  4. 协同设计、研发推进活动链路及状态细节确认
- 成果：预计分享率+8% | 新用户转化+5% | 节点串联4个
- 洞察：活动设计的重点不只是玩法本身，而是整条链路是否可理解、可分享、可转化。但整体营收无显著提升，成本收益不成正比。

## 项目3：助眠音频内容引入（4星）
- 类型：内容策略
- 问题：助眠场景既是高频健康服务场景，也是会员内容商业化的重要方向。现有内容供给的丰富度和体系化程度有限。
- 方案：
  1. 完成竞品分析，拆解内容类型、免费/付费分层模式、内容组织方式
  2. 参与音频招标和供应商方案比选，评估价格、授权期限、质量和内容丰富度
  3. 设计3阶段共200首音频的内容引入方案
  4. 设计"免费体验+VIP内容承接"的分层策略
- 成果：内容供给200首 | 使用时长+10%~15% | 会员转化+3%~5%
- 洞察：健康类产品里的内容能力，不只是服务用户体验，也是在建设会员价值和长期留存能力。

## 项目4：会员体系竞品分析（4星）
- 类型：竞品分析
- 问题：小米运动健康App会员体系需要明确核心权益方向，缺乏系统性的用户需求数据支撑。
- 方案：
  1. 基于81989份有效问卷数据进行用户画像和功能诉求分析
  2. 发现用户最关注健康（77.5%）和专注（61.4%）两大功能
  3. 识别睡眠（61.4%）和白噪音（61.4%）为二级功能绝对高点
  4. 为会员核心权益指明方向
- 成果：问卷样本81989份 | 健康关注度77.5% | 睡眠关注度61.4%
- 洞察：用户调研不是简单的数据统计，而是从数据中找到产品方向的关键信号。
